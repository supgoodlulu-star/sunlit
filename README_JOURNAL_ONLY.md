# Sunlit Journal 0.8.6-journal · Forge 1.20.1

수첩 전용 버전입니다. main 4cedc92에서 분기했으며 preview/sakura-reference의 스킨 변경은 합치지 않았습니다.

## 포함
프로필 / 생활 기술 / 업무 일지 / 업적 도감 / 칭호 도감, 정확히 5개 탭입니다.
프로필은 실제 플레이어 미리보기·Server Nick 닉네임·대표 칭호·바닐라 레벨과 다음 레벨 경험치·업무 요약을 표시합니다.
생활 기술은 Pufferfish Skills 0.16.1 공개 API의 실제 카테고리와 레벨/경험치/해금 기술을 읽습니다. 카테고리는 서버 설정을 따르며 8가지 아이콘을 8개 고정 스킬로 간주하지 않습니다. 연동이 없으면 예시 레벨을 만들지 않습니다.
칭호는 전체/획득/미획득 필터, 테마 색상, 조건·진행도, 대표 장착·해제를 제공합니다. 채팅은 기존 Server Nick 연동과 메시지 중복 방지를 유지합니다.
쉬프트+허공 우클릭 또는 Minecraft 조작 설정의 ‘프로필 열기’로 엽니다. 단축키는 모드팩 충돌을 피하려고 기본 미지정입니다. `sunlit_journal_core-client.toml`에서 허공 제스처를 끌 수 있습니다.

## 보상 계약
일일은 농사·낚시·채광·요리·목축 각 1개(5개), 주간은 서로 다른 3개 분야입니다.
각 업무 보상은 일일 황동 동전 2 + 바닐라 경험치 20, 주간 동전 6 + 경험치 80과 해당 분야 무작위 재료 1종입니다.

| 분야 | 일일 후보 수량 | 주간 수량 |
|---|---|---|
| 농사 | 저등급/약한/보습 비료 12/12/14 | 36/36/42 |
| 낚시 | 지렁이 18 또는 통발 미끼 14 | 54 또는 42 |
| 채광 | 석탄/구리 주괴/철 주괴 64 | 96 |
| 요리 | 설탕/알프스 소금 18 | 54 |
| 목축 | 동물 먹이 18/22/26 | 54/66/78 |

`TaskRewards.POOLS`의 기존 아이템 ID를 유지합니다. 재료는 업무 생성 시 `payout` NBT에 저장되며 갱신·재접속·서버 재시작으로 다시 뽑지 않습니다. 보상 아이템이 없으면 수령을 소모하지 않고 동전/경험치도 부분 지급하지 않습니다. 운영자가 실제 아이템 ID를 확인해야 하며 임의 대체 보상은 없습니다. 계절 공동 축제의 기존 에메랄드 16 + 경험치 160은 유지했습니다.
업무 갱신은 기존 저장 데이터와 같은 서버 UTC 날짜/월요일 기준입니다.

## 제외 및 저장 호환성
뽑기·스킨 공방·히든맵 신규 진입·뽑기권 교환·일일/주간 뽑기 보너스를 제거했습니다. 해당 네트워크 액션 및 명령, 모델 프로퍼티·툴팁·바닐라 도구 모델 덮어쓰기도 없습니다.

- 기존 mod ID, 월드 저장 키 `sunlit_journal_alpha4`, 플레이어 칭호 키 `SunlitJournalTitles`를 유지합니다.
- 진행 중/수령 완료 업무, 확정 보상, 소유 칭호, 기존 `fantasyGacha`/`skyGarden` 원본 NBT와 예전 장비의 스킨 태그는 삭제하지 않습니다. 서버 스냅샷에서는 퇴역 콘텐츠 NBT를 빼고 보냅니다.
- 기존 뽑기권/조각/유물 아이템·블록 ID와 빈 차원 정의는 세이브 로딩을 위한 호환 장치입니다. 뽑기권과 조각은 사용할 수 없고 새로 지급하지 않습니다. 기존 아이템 스택을 임의로 화폐로 교환하지 않습니다.
- 기존 장비는 바닐라 외형으로 보이지만 아이템·내구도·인챈트·이름·저장 태그는 보존합니다. 구버전 리소스팩을 별도로 적용하면 그 리소스팩의 외형이 보일 수 있습니다.
- 예전 차원 안에서 저장한 플레이어는 로그인 시 기존 귀환 정보 또는 오버월드로 복귀합니다. 신규 맵 생성·입장 경로는 없습니다.
- 이전 하늘섬 칭호 ‘구름 위의 손님’·‘하늘 정원의 수호자’는 제거했습니다. 업데이트 후 플레이어가 접속하거나 칭호 데이터가 로드될 때 두 칭호의 보유 기록을 정리하고, 장착 중이었다면 해제합니다. 다른 칭호·업무·보상은 보존합니다.
- 네트워크 프로토콜 `journal-10`이므로 서버·클라이언트를 함께 교체하세요. 기존 Sunlit JAR와 동시 설치하지 마세요. 월드 복사본에서 먼저 업그레이드를 확인하세요.

## 빌드·검증
JDK 17과 Gradle Wrapper를 사용합니다.

```sh
./gradlew clean build
./gradlew runGameTestServer
./gradlew -PintegrationMods=true -PintegrationModDir=/path/to/mods runGameTestServer
```
연동 검사에는 제공된 Server Nick 1.2.0 / Pufferfish Skills 0.16.1 / Patchouli 85 JAR가 필요합니다. `tools/reward-fixtures`는 테스트 전용 대체 아이템이며 배포 JAR에 포함하지 않습니다.
실제 클라이언트 UI·입력·보상 검사 방법은 `tools/visual-preview/README.md`를 참고하세요. 해당 도구와 이전 스킨/맵 도구는 기본 배포 소스 세트에 포함되지 않습니다.
이전 README·VALIDATION·스킨 문서와 downloads/resourcepack은 0.7까지의 역사 자료입니다. 현재 배포 범위 및 검증은 이 문서와 JOURNAL_VALIDATION.md를 기준으로 합니다.
