# 0.9.2-fox-bb-dev 설치 및 테스트

이 버전은 첨부 Blockbench 여우를 적용한 시험본입니다. [외형과 성능 제한](FOX_BLOCKBENCH_0.9.2.md)을 먼저 확인하세요.

이 빌드는 수첩 0.8.6을 포함한 펫 외형 개선 개발 빌드이다. 기존 0.9.0 펫 개체·장식 해금 기록과 저장 형식은 유지한다. 기존 스킨 뽑기를 다시 켜는 버전이 아니다. 디자인 시안과 동일한 최종 아트 버전은 아니며 현재 2차 모델을 실제 게임에서 확인할 수 있다.

1. Forge 1.20.1(검증: 47.3.0), Java 17 환경에서 사용한다.
2. 기존 Sunlit JAR를 이 JAR로 교체한다. 같은 모드 ID이므로 두 JAR를 동시에 넣지 않는다. 서버와 클라이언트에 같은 버전을 설치한다(네트워크 journal-11).
3. 기존 데이터가 있는 서버는 복사한 테스트 세계에서 먼저 확인한다. 구버전으로 되돌리려면 새 버전 실행 전 세계 백업을 사용한다. 새 펫 레지스트리를 구버전이 읽을 수 있다는 의미의 하위 호환은 제공하지 않는다.
4. 운영자가 스폰에서 `/sunlitpets place`로 자판기와 장식 가게를 설치한다. 명령 실행자의 앞쪽 두 칸과 그 위가 비어 있어야 한다. 기존 스폰 건물을 자동 수정하지 않는다.
5. 프로필의 **펫 보관함** 또는 `/sunlitpets`로 보관함을 연다. 펫 인형을 손에 들고 우클릭하면 등록한다. 보관함에서 한 마리를 소환/회수하고, 인형으로 꺼내어 다른 사람에게 줄 수 있다.
6. 자판기는 펫 전용 뽑기권을 **한 장씩** 소비한다. 장식 가게는 인벤토리의 이리듐 동전으로 일반 10개, 전설 20개를 차감하여 해당 플레이어에게 종별로 영구 해금한다.

관리자 외형 확인: `/sunlitpets give fox`, `/sunlitpets give baby_dragon`, `/sunlitpets give winter_fairy`. 일반 `/give`로 만든 빈 인형은 개체 발급 기록이 없어 등록할 수 없다. 테스트 뽑기권: `/give @s sunlit_journal_core:pet_ticket 1`.

동전 기본 ID는 `numismatics:sun`이다. 실제 서버의 동전 ID가 다른 경우 `config/sunlit-pets.toml`의 `iridiumCoin`을 지정한다. 없는 아이템을 다른 재화로 대신 받지 않는다.

기존 업무 보상 내용과 업무 완료 보너스 정책은 이 기능으로 변경하지 않았다. 생활 뽑기권 확률 및 검증 범위는 SPEC.md와 VALIDATION.md를 참고한다.
