`/자랑하기`와 일반 채팅의 `[아이템]`으로 손에 든 아이템을 전체 채팅에 공유합니다. 아이템 이름 위에 마우스를 올리면 실제 툴팁을 표시합니다. [사용법과 실제 게임 화면](ITEM_SHOWCASE_0.8.7.md).
