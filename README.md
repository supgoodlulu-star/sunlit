# Sunlit · 모험가의 수첩

Minecraft 1.20.1 / Forge 47.3.0용 **0.4.2 개발 버전**입니다.

- [설치용 JAR 다운로드](https://github.com/supgoodlulu-star/sunlit/raw/refs/heads/main/downloads/sunlit-journal-core-0.4.2-dev.jar)
- [통합 소스 ZIP 다운로드](https://github.com/supgoodlulu-star/sunlit/raw/refs/heads/main/downloads/Sunlit_Journal_ALPHA4_2_Integrated_Source.zip)
- [설치 방법·기능·업무 설정](README_한국어.md)
- [검증 범위](VALIDATION.md)

기존 Sunlit JAR을 제거한 뒤 새 JAR을 `mods` 폴더에 넣으세요. 호스트와 접속자 모두 교체합니다. 수첩은 `/sunlit journal`로 엽니다.

이번 버전은 생활 기술·업적을 둥근 카드로 나누고, 분야별 아이콘·업적 진행 방법·필터를 추가했습니다. 업무는 지정된 작물·물고기·광석·음식·동물만 집계합니다. 표시할 수 없는 연동 정보의 진단 문구는 화면에서 생략합니다.

아래는 실제 Minecraft 클라이언트에서 **예시 데이터**로 촬영한 UI입니다. 실제 모드팩 플레이나 계절·경제 연동 검증 결과는 아닙니다.
