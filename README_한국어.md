# Sunlit Journal 0.6.1 · 환상 도구 스킨 컬렉션

Minecraft 1.20.1 / Forge 47.3.0 / Java 17. 서버와 모든 접속자가 같은 JAR을 설치합니다. mods 폴더의 이전 Sunlit JAR을 새 버전으로 교체하고 재시작하세요.

## 0.6.1 디자인 변경

60종의 도구 머리·손잡이를 테마별로 새로 조형했습니다. 칼날과 도구 머리는 폐쇄된 두꺼운 단면·융기 면·모따기를 가지며 손잡이는 감은 그립·목재 가지·육각 금속·수정·땋은 덩굴 등으로 구분합니다. 밝은 면·짙은 옆면·그립·보석의 재질을 따로 사용합니다.

스킨 ID·확률·기존 소유·장착 상태와 아래 업무/조각 규칙은 0.6.0과 같습니다. 기존 장비도 업데이트하면 새 외형으로 표시됩니다. [모델별 변경과 실제 게임 비교](SCULPTED_SKINS.md).

## 공방 열기

- `/sunlit gacha` 또는 수첩의 **스킨 공방 → 공방 열기**.
- 뽑기권이나 조각을 손에 들고 일반 우클릭해도 열립니다. 쉬프트+허공 우클릭은 기존 프로필 동작입니다.
- 수첩은 `/sunlit journal`, 쉬프트+허공 우클릭 또는 조작 설정에서 지정한 키로 엽니다.

## 업무 완료 보상과 조각 교환

- **일일 업무 3개 모두 완료 → 뽑기권 조각 1개**.
- **주간 업무 3개 모두 완료 → 뽑기권 1장**.
- 각 업무의 진행도가 목표에 도달하면 기간당 한 번 자동 지급합니다. 개별 업무의 에메랄드/경험치 보상은 기존처럼 수령합니다. 업무마다 뽑기권을 지급하지 않습니다.
- **조각 10개 → 뽑기권 1장**. 공방의 교환 버튼을 누르면 인벤토리 조각을 정확히 10개 소비합니다. 9개로는 교환할 수 없습니다.
- 날짜/주차는 기존과 동일하게 서버 UTC 일자, 월요일 시작입니다. 날짜가 뒤로 가도 보상 기간을 다시 열지 않습니다. 기간 변경 시 새 업무와 완료 보상으로 갱신합니다.
- 아이템은 인벤토리로 지급합니다. 가득 차면 플레이어에게 귀속된 드롭으로 전달합니다.

## 60종 3D 치장과 뽑기

12개 테마 × 검·곡괭이·도끼·삽·괭이 5종입니다. 컬렉션과 테마 목록·확률은 [FANTASY_COLLECTION.md](FANTASY_COLLECTION.md)에 있습니다.

- 1회: 뽑기권 1장, 10회: 10장. 매회 독립 추첨이며 등급 보장이나 누적 확정 보상은 없습니다.
- 중복은 **별가루 1개**로 전환합니다. 별가루 5개로 미보유 스킨 1종을 선택 교환합니다. 이는 뽑기권 조각과 별도입니다.
- 결과 카드를 클릭하면 해당 스킨 미리보기로 이동합니다. 보유 스킨과 같은 종류의 장비를 주 손에 들고 적용합니다.
- 바닐라 나무·돌·철·금·다이아몬드·네더라이트 30종 장비를 지원합니다. 원래 아이템, 능력치, 내구도, 이름, 인챈트는 보존합니다.
- 외부 CustomModelData가 있는 장비는 덮어쓰지 않습니다. 다른 모드의 도구나 바닐라 모델을 대체하는 리소스팩은 별도 통합이 필요합니다.
- 수집 기록과 최근 뽑기 결과·별가루는 월드의 UUID별 데이터로 저장합니다. 장비 외형은 아이템 NBT로 보존되므로 다른 플레이어에게 전달한 장비도 외형이 유지됩니다.

## 기존 기능과 히든맵 제외

프로필·생활 기술·일일/주간/계절 업무·공동 축제·색상 칭호 채팅·키/쉬프트 우클릭 열기를 유지합니다. Serene Seasons·Pufferfish Skills·Server Nick·Numismatics는 기존 선택적 연동 방식입니다.

이번 버전에는 하늘 정원 입장·건축 생성·퍼즐·히든맵 보상이 없습니다. ‘비밀 기록’ 탭은 ‘스킨 공방’으로 교체했으며 나침반 제작법을 제거했습니다. 이전 월드의 차원/레지스트리 정의와 귀환 코드는 기존 저장 파일 보호를 위해 남겼습니다. 정원에 있던 플레이어는 로그인 시 돌아옵니다. 기존 아이템·칭호 기록을 삭제하지 않습니다.

## 운영/빌드

운영자 테스트 지급: `/give @s sunlit_journal_core:fantasy_ticket 10`, `/give @s sunlit_journal_core:fantasy_ticket_fragment 10`.

Windows `gradlew.bat build`, Linux/macOS `./gradlew build`. 결과 `build/libs/sunlit-journal-core-0.6.1-dev.jar`. 코드·OBJ 모델·텍스처가 JAR에 포함되어 별도 모델 로더 모드를 설치하지 않습니다.

확률과 모델 원본은 `src/main/resources/data/sunlit_journal_core/fantasy_skins.json`, `assets/sunlit_journal_core/models/fantasy/`, 생성기는 `tools/generate_fantasy_collection.py`입니다. 생성 후 `tools/validate_fantasy_collection.py`로 검사합니다.

실제 모델은 시안의 형태를 게임에 맞게 단순화한 곡면 OBJ입니다. 시안 이미지의 PBR 재질·시네마틱 조명·반투명 보석 렌더를 그대로 재현한 것은 아닙니다. [검증 범위](VALIDATION.md), [이전 개발 기록](HISTORY_PRE_0_6.md).
