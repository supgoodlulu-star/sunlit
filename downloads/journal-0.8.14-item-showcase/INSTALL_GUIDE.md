# 등급 색상 아이템 자랑 — 0.8.14

서버와 모든 클라이언트에서 기존 수첩 JAR를 sunlit-journal-core-0.8.14-item-showcase.jar 하나로 교체합니다. 기존 버전과 중복 설치하지 마세요. Reforged는 앞서 받은 1.0.0-dev.8을 그대로 사용합니다. 리소스팩과 글꼴 보정도 그대로 사용합니다. 별도 데이터팩 설치는 필요하지 않습니다.

/자랑하기는 전체 채팅에 다음과 같이 두 줄로 표시합니다.

✿ 룰루님의 소중한 아이템 ✿
└ ✦ [아이템 이름] ✦

닉네임 색상은 유지하며 안내는 크림색, 꽃·별·연결선은 꿀빛입니다. 일반 채팅의 [아이템]도 ✦ [실제 아이템 이름]으로 바뀝니다. 수량이 여러 개면 × 수량을 유지합니다.

아이템 이름은 Sunlit Reforged의 현재 잠재등급에 맞춰 표시합니다: 레어 #55AAFF / 에픽 #BB66FF / 유니크 #FFCC44 / 레전드리 #55DD88. 공방과 같은 색상입니다. 직접 이름을 붙인 장비도 채팅에서만 등급 색상을 우선합니다. 원본 아이템의 이름·색상·인챈트·내구도·잠재옵션·기타 NBT는 수정하지 않습니다. 잠재등급이 없는 아이템은 기존 아이템 표시 색상을 유지합니다. 저장 스키마 1과 2를 읽으며 알 수 없는 형식은 등급을 임의로 정하지 않습니다.

아이템 이름에 마우스를 올리면 복사된 실제 아이템의 기본 툴팁과 설치된 모드의 잠재능력 정보가 표시됩니다. 자랑 뒤에 손의 아이템을 바꿔도 기존 채팅의 아이템 정보는 유지됩니다. 빈손·취소된 채팅 처리와 재접속 데이터는 기존대로입니다.

Minecraft 1.20.1 / Forge / Java 17. 소스 빌드: ./gradlew build. 이번 변경은 수첩의 채팅 표시만 바꾸며, 강화 수치·확률·가격·보상·장비 지원 범위는 바꾸지 않습니다.
