# 검증 범위

- 수첩 서버 GameTest 51개: 기존 기능 및 저장된 옛 자산 단위를 새 SUN으로 표시하는 검사.
- 꿈방울 서버 GameTest 24개: 실제 Create Numismatics 은행에서 500/2,500/10,000 SUN 구매·잔액 부족·인벤토리 부족·중복 요청 검사. 은행 4,096 → 3,596 → 1,096 SUN 차감 및 수첩/상점의 단위 일치를 확인합니다.
- 실제 라디오 볼펜 글꼴팩 + 기존 볼드 보정 모드에서 입력칸 렌더 호출의 그림자=false를 검사합니다. 포커스·선택·긴 입력·작은 GUI·커서/백스페이스·갱신 중 편집 유지와 커서 앞뒤 배치를 확인합니다.
- 실제 게임에서 상점 구매·잠재능력 선택·복원·작은 GUI 클릭을 확인합니다.

별도 테스트 월드 및 관련 모드 조합 검사입니다. 전체 사용자 모드팩과 Essential 두 사용자 접속을 새로 검증한 것은 아닙니다. 기존 Reforged 원본 접두사 연동 미완료 상태도 그대로입니다.
