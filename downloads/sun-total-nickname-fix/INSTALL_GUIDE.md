# 닉네임 겹침 수정 + SUN 총가격 기준

서버와 클라이언트 모두 아래 두 파일로 기존 JAR 하나씩을 교체합니다. 이전 버전과 중복 설치하지 마세요.

- sunlit-journal-core-0.8.13-nickname-text.jar
- sunlit-reforged-1.0.0-dev.6.jar

기존 라디오 볼펜 리소스팩과 sunlit-font-bold-fix-1.0.0.jar는 그대로 사용합니다. 이번 수정은 수첩 닉네임 입력칸의 그림자만 제거합니다. 입력·선택·커서·다른 화면의 글꼴을 교체하지 않습니다.

SUN은 코인 툴팁의 ‘총 가격’ 기준입니다. 구리 1 / 아연 8 / 철 16 / 황동 64 / 금 512 / 이리듐 4,096 SUN입니다. 계좌 잔액을 새로 생성하거나 환전하지 않습니다. 기존 은행의 최소 단위 잔액을 그대로 읽습니다.

꿈방울 단가는 작은 500 / 영롱한 2,500 / 찬란한 10,000 SUN입니다. 이리듐 1개 상당의 은행 잔액 4,096 SUN에서 작은 꿈방울을 구매하면 3,596 SUN이 남습니다. 기존처럼 개인 은행 계좌에서 차감하며 인벤토리 현금을 직접 소비하는 기능을 추가하지 않습니다.

이번 SUN 단위 변경은 JAR 코드에 적용되므로 데이터팩만 교체해서는 적용되지 않습니다. 기존 잠재능력 설정 데이터팩은 유지해도 됩니다. pricesSun은 새 SUN 단위로 해석되며, 함께 제공한 default.json은 승인된 10개 옵션 수치와 500/2500/10000 가격을 유지한 전체 설정입니다. 변경할 경우 기존 파일을 교체한 뒤 /reload를 실행합니다.

잠재능력 수치·승급 확률·드롭·업무 보상 아이템은 바꾸지 않았습니다. 기존 장비와 선택 대기 결과, 소유 칭호, 은행 잔액 및 명예의 전당 기록은 유지합니다. 자산 업적의 실제 필요 저축액은 유지하고 새 단위로 환산해 표시합니다.

Minecraft 1.20.1 / Java 17 / Forge. 소스 빌드: 수첩은 루트 ./gradlew build, 꿈방울은 addons/reforged/gradlew -p addons/reforged build.
