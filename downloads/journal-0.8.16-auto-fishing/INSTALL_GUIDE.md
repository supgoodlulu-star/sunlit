# 자동낚시 — 0.8.16

Minecraft 1.20.1 / Forge 47.4.0 / Java 17 / Stardew Fishing 3.7 기준입니다.

## 설치와 사용

서버와 모든 클라이언트의 기존 sunlit-journal-core JAR를 sunlit-journal-core-0.8.16-auto-fishing.jar 하나로 교체합니다. 이전 수첩 JAR와 중복 설치하지 마세요. Reforged 1.0.0-dev.8, 기존 글꼴 보정, 리소스팩과 물고기 크기 판매함 스크립트는 그대로 사용합니다.

설치 ZIP에는 새 수첩 JAR와 변경 없는 물고기 판매함 스크립트를 함께 제공합니다. 이미 0.8.15 스크립트가 있으면 같은 파일을 유지하면 됩니다. 서버와 클라이언트를 재시작합니다.

주 손에 낚싯대를 들고 물에 찌가 떨어질 방향을 바라본 다음 F8을 누릅니다. 자동 투척 → 실제 입질 감지 → 회수 → 미니게임 막대 자동 조작 → 원래 결과/상자 연출 → 실제 보상 수령 → 재투척을 반복합니다. 화면 왼쪽 위에 자동낚시 ON과 현재 상태를 표시합니다.

같은 키로 끕니다. 설정 → 조작 → 키 설정 → 모험가의 수첩의 ‘자동낚시 켜기 / 끄기’에서 단축키를 바꿀 수 있습니다. 기본 F8이 다른 기능과 겹치면 이 항목을 원하는 키로 변경하세요. 기존 프로필 열기 단축키는 유지합니다.

보물상자가 나오면 물고기와 함께 수집할 수 있는 위치를 우선합니다. 떨어져 있는 상자는 진행도 여유가 있을 때 시도하고 위험해지면 물고기로 돌아옵니다. 일반/황금 보물상자 등장과 보상은 원래 모드의 확률·획득 판정에 따릅니다. 모든 물고기나 상자의 획득을 보장하지는 않습니다.

## 중지와 기존 기능

- F8을 다시 누르거나 월드에서 직접 우클릭하면 자동 조작을 끕니다.
- 낚싯대/선택 핫바 슬롯 변경, 파손, 사망/관전, 접속 종료/월드 변경 시 끕니다.
- 인벤토리·수첩·설정 등 다른 화면을 열면 끕니다. 자동으로 다시 켜지지 않습니다.
- 인벤토리가 가득 차도 계속 낚시합니다. 들어가지 못한 물고기·보물은 기존 낚시처럼 바닥에 떨어집니다.
- 찌가 생물에 걸리거나 투척/회수 응답이 지연되면 중지 안내를 표시합니다.

미니게임 도중 OFF는 자동 누르기 입력을 해제합니다. 진행 중인 미니게임은 수동으로 이어 하거나 원래 방법으로 닫을 수 있습니다. 상자를 클릭하거나 성공 값을 강제로 보내는 기능이 아니라, 원래 FishingScreen의 누르기/놓기 입력 API를 사용하는 방식입니다. 완료와 결과 패킷, 미끼 소모·낚싯대 내구도·서버 보상은 기존 낚시 코드가 처리합니다.

일반 낚싯대와 기존 모드팩 낚싯대를 대상으로 합니다. 코드상 FishingRodItem / Forge 낚싯대 동작을 인식하며 실제 일반·넵튜늄 반복 낚시를 확인했습니다. 철·금·다이아·넵튜늄·용암 낚싯대의 장비 인식도 검사했습니다. 용암 낚시의 전체 실전 사이클은 이번 검증에 포함하지 않습니다.

잠재능력·물고기 크기·포획자/최대어 기록·자랑 채팅·품질·판매함 배율·승급/가격/업무 보상은 유지합니다. 자동낚시 설정이 어종 등장 조건이나 보물 확률을 변경하지 않습니다. 기존 플레이어 데이터와 아이템 레지스트리를 바꾸지 않습니다.

전체 사용자 모드팩과 Essential 원격 2인 접속은 별도 현장 확인이 필요합니다. 실제 게임 캡처와 검사 범위는 TEST_RESULTS.md를 참조하세요.

소스 빌드: ./gradlew -PforgeVersion=47.4.0 build. 외부 모드 JAR는 포함하지 않습니다.
