# 검증

필수 서버 GameTest 61개 모두 통과 및 build 성공. 기존 수첩/채팅 52개를 유지하고 낚시 크기·판매 관련 9개를 추가했습니다.

- 확률 경계와 승인된 가격 배율, 어종별 길이 구간 및 정수 반올림 경계.
- 실제 바닐라 낚시 테이블의 전역 전리품 수정자, 실제 Stardew Fishing 보상 리스트 이벤트.
- 저장/복원·중복 처리 시 크기 재추첨 방지, 기존 물고기와 알 수 없는 데이터 유지.
- 보상 묶음 수량 및 추가 스킬 처리 단위, 비물고기, 외부 이름/NBT/품질 보존.
- 실제 Quality Food applyQuality API 후 크기 보존. 원래 어종이 아닌 가공 결과의 배율 무효화.
- 지급 전 기록 미부여, 지급 후 개인 최대어 기록과 중복/타인 교환 시 기록 도용 방지.
- 원본 4.1.5A 판매 계산 함수를 실제 KubeJS/Rhino에서 실행: 품질·판매 속성·블루길 특수 스테이지·기존 가격·수량·혼합 재고·판매 불가 아이템·미리보기·제거 슬롯·즉시 제거 검증.
- 실제 게임 클라이언트: 5종 크기를 서버 코드로 생성하고 인벤토리 패킷 및 기본 툴팁의 길이/크기/배율/포획자 확인. 자랑 명령어의 실제 SHOW_ITEM 호버와 품질 NBT 유지 확인.
- JAR와 설치 ZIP의 동일 파일/스크립트 일치, QA 클래스 제외, 전체 소스 ZIP 원본 파일별 일치 검사.

스크린샷은 실제 테스트 월드이며 생성 이미지가 아닙니다. 크기 구간을 검증하기 위해 서버에서 테스트 어획물을 생성했으며, 실전 낚시에서 당첨된 결과라는 의미는 아닙니다. 개인 최대어 데이터·코인·기존 장비는 실제 사용자 데이터가 아닌 격리된 테스트 저장을 사용했습니다.

전체 사용자 모드팩에서 실물 기본/스마트 판매함 블록을 설치해 코인을 수령하거나 Essential 2인 접속을 실행한 검증은 아닙니다. 원본 판매함의 공통 계산 경로와 제거 동작을 검증했고 코인 출력 함수는 변경하지 않았습니다.
