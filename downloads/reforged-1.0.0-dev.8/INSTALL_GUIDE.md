# 선릿밸리 모드 장비 재련 지원 — dev.8

서버와 모든 클라이언트에서 기존 Sunlit Reforged JAR를 sunlit-reforged-1.0.0-dev.8.jar 하나로 교체합니다. 이전 JAR와 중복 설치하지 마세요. Minecraft 1.20.1 / Forge 47.4.0 / Java 17 기준입니다. 수첩 sunlit-journal-core-0.8.13-nickname-text.jar와 기존 글꼴 보정은 그대로 사용합니다.

이번 변경은 재련 가능한 장비 범위를 확장합니다. 기존 장비의 잠재능력·외부 NBT·인챈트·이름·내구도·낚싯대 부속품을 보존합니다. 새 장비를 따로 지급하거나 교체하지 않습니다. 공방 장비 슬롯에 넣고 기존 꿈방울을 사용하세요.

추가 낚싯대: Aquaculture 철 / 금 / 다이아몬드 / 넵튜늄 낚싯대와 Nether Depths Upgrade 용암 낚싯대. 기존 일반 낚싯대도 지원합니다. 낚싯대에는 희귀 물고기, 보물상자, 막대 크기, 생활 경험치, 내구도 옵션 풀이 적용됩니다.

추가 도구: 넵튜늄, 마나강철, 엘레멘티움, 테라강철, 일렉트럼 도구와 상위 검, 다이아몬드·네더라이트 나이프/채굴 망치. 모드팩 KubeJS의 갤럭시 검, 미야우마겟돈, 용의 이빨 도끼는 제작 경로에 맞춰 별도 지원합니다. 넵튜늄·테라강철 방어구도 방어구 옵션으로 지원합니다. 정확한 검증 ID와 분류는 SUPPORTED_EQUIPMENT.md를 참조하세요.

검·도끼·나이프는 무기 옵션, 곡괭이·채굴 망치는 곡괭이 옵션, 괭이·삽·방어구는 해당 기존 옵션 풀을 사용합니다. 일반 도구는 실제 도구 등급이 다이아몬드 채굴 등급 이상인지와 클래스/태그를 확인합니다. 목재·돌·철·금 바닐라 도구는 계속 제외합니다. 모드팩이 금의 채굴 등급만 올려도 금 장비를 자동 허용하지 않습니다. 채굴 등급이 상향된 금 채굴 망치도 자동 분류에서 제외합니다. 활·물뿌리개·회칼 등 기존 옵션 분류가 없는 유틸리티는 임의로 추가하지 않습니다.

가격 500 / 2,500 / 10,000 SUN, 승급 확률, 21옵션 수치와 가중치, 업무 보상, 기존 호환 형식은 dev.7 그대로입니다. 막대 증가율 30 / 50 / 75 / 100%, 보물 10 / 20 / 30 / 50%, 희귀 물고기 5 / 10 / 20 / 40%입니다. SUN은 코인 총가격 단위이며 황동 64 / 이리듐 4,096 SUN입니다.

기존 잠재능력 데이터팩은 그대로 사용할 수 있습니다. 제공한 sunlit_balance.zip과 default.json은 이전 버전과 같은 수치입니다. 별도 장비 지원용 데이터팩 설치는 필요하지 않습니다. 장비 분류 태그가 JAR에 포함됩니다.

추가 장비를 수동으로 분류하려면 데이터팩의 data/sunlit_reforged/tags/items/reforgeable/{weapon,armor,pickaxe,hoe,shovel,rod}.json에 선택한 분류의 아이템 ID를 추가합니다. 예: {"replace":false,"values":[{"id":"example:special_pickaxe","required":false}]}. 한 아이템은 한 분류에 넣고 서버에서 /reload 하세요. 태그는 서버에서 클라이언트로 동기화되어 슬롯·버튼·실제 재련·효과 판정에 함께 적용됩니다. excluded.json 태그는 채굴 등급만 상향된 하위 장비를 자동 분류에서 제외합니다. 명시적인 분류 태그는 이 자동 제외보다 우선합니다. 태그로 재련을 허용해도 외부 모드에 없던 도구 동작이나 새 옵션이 생기지는 않습니다.

실제 관련 모드 JAR와 원본 KubeJS 무기 등록 스크립트로 검증했습니다. 사용자 전체 모드팩 및 Essential 2인 접속 전체 검증은 아닙니다. 원본 Reforged JAR 미제공으로 해당 접두사 시스템의 연동 완료판은 아닙니다.

소스 빌드: addons/reforged/gradlew -p addons/reforged build. 외부 모드 JAR는 동봉하지 않습니다. qa/modpack-check.gradle은 실제 모드 검증용 의존성과 스크립트 설치만 추가하며 배포 JAR에는 QA/테스트 코드를 넣지 않습니다.
