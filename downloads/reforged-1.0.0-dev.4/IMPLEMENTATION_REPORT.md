# 꿈방울 적용 내역

## 외형과 표시
첨부 시안의 파란 병 / 분홍·보라 병 / 오로라 금장 병을 바탕으로 배경과 외부 파티클을 제거한 투명 컷아웃을 제작했습니다. 이미지 편집 생성 도구로 제작해 원본 픽셀과 완전히 동일한 추출본은 아닙니다. 컷아웃 원본과 게임용 128×128 RGBA PNG를 함께 제공합니다.

인벤토리·공방은 투명 아이콘, 손·드롭·아이템 액자는 별도 입체 모델을 사용합니다. Forge separate_transforms 로더로 시점에 따라 선택합니다. 작은/영롱한 모델은 각각 66개, 찬란한 모델은 73개의 큐보이드로 둥근 몸체·목·마개·리본·별 장식을 구성했습니다. 평면 아이콘에 두께만 준 모델이 아닙니다. 유리와 액체는 UV 텍스처의 명암·물결로 표현하며 실제 굴절이나 액체 시뮬레이션은 없습니다. 입체 모델은 시안의 세부 장식을 Minecraft 요소로 재구성했으므로 2D 이미지와 완전 일치한다고 주장하지 않습니다.

게임용 모델 JSON, 시안 액체 부분을 옮겨 담은 UV 아틀라스, 텍스처가 포함된 Blockbench java_block 프로젝트 3개와 재생성 스크립트를 제공합니다. 모든 글자·가격·강화 결과는 기존 게임 데이터로 표시합니다. 공방의 큐브 문구·아이콘·이름을 꿈방울로 바꾸고 종류별 툴팁을 추가했습니다.

## 보존
기존 아이템 레지스트리 ID, 스택 크기, 희귀도, 우클릭 동작 및 내부 Cube enum/class를 유지합니다. 새로운 아이템을 등록하지 않습니다. 확률·가격·19종 옵션·풀·장비 NBT·승급·기존/신규 선택·드롭·보상·은행 거래 로직은 그대로입니다.

표시 이름: suspicious_cube → 작은 꿈방울, artisan_cube → 영롱한 꿈방울, master_cube → 찬란한 꿈방울.

첫 사용 레어 3줄, 승급 8%; 15%/5%; 25%/12%/3%, 기존 줄 선택 시 승급 유지 규칙을 바꾸지 않았습니다. 기존 상위 등급 장비의 등급을 낮추거나 별도의 사용 제한을 추가하지 않았습니다.

## 범위
실제 관련 모드 조합 및 Forge 클라이언트에서 검사했습니다. 전체 모드팩·Essential 2인 접속 검증을 새로 수행한 것은 아닙니다. 기존 접두사 연동 미완료 상태는 유지됩니다.
