# Sunlit 펫 — 0.9.0 개발 명세

기존 수첩·업무·축제 데이터 및 보상은 유지한다. 새 펫 뽑기는 폐기한 스킨 뽑기와 별개이다.

일반 40종 95%, 전설 20종 5%. 현재 계절 전설은 상대 가중치 1.5배(3:2), 계절 연동 불가 시 균등. 모든 계절 펫을 연중 획득할 수 있다. 한 번에 한 장만 소비한다.

개체 UUID가 있는 3D 펫 인형 → 우클릭 등록 → 프로필의 보관함에서 한 마리 소환. 중복 허용. 다시 아이템화하여 거래한다. 장식은 구매자에게 종별 영구 해금되며 인형에 포함되지 않는다. 일반 장식 10, 전설 장식 20 이리듐 동전. 1 이리듐=64 황동이라는 사용자 서버 기준을 따른다.

전투·능력치·허기 없이 따라오기와 쓰다듬기. 전설은 계절 파티클. 요정은 플레이어 머리 크기, 나머지 전설은 카피바라 수준. 용은 큰 머리·짧은 주둥이·뒷다리 두 개·작은 앞팔과 상아색 이마 비늘.

## 검증 구분

기존 외형 시트는 디자인 시안이다. 코드의 모델과 실제 게임 캡처를 별도 검증하여 보고한다.

## 운영 및 데이터

- `/sunlitpets`: 보관함. 프로필의 **펫 보관함** 버튼으로도 연다.
- `/sunlitpets recall`: 소환 해제.
- 관리자 `/sunlitpets place`: 앞쪽 두 빈 칸에 자판기와 장식 가게 설치. 기존 스폰 건물을 자동으로 덮어쓰지 않는다. 스폰에서 운영자가 배치한다.
- 관리자 `/sunlitpets give <species_id>`: 해당 개체 인형 발급. 일반 `/give`로 만든 빈 인형은 등록되지 않는다.
- 새 데이터 `world/data/sunlit_pets_v1.dat`. 기존 수첩/칭호 NBT와 별도. 개체 UUID와 발급 토큰을 서버에서 검증한다. 아이템화할 때 토큰을 바꿔 이전 인형 사본의 재등록을 차단한다.
- 장식은 인벤토리의 `numismatics:sun` 동전으로 직접 구매한다. 은행 계좌를 자동 출금하지 않는다. 연동 아이템이 없으면 구매를 거절한다. `sunlit-pets.toml`의 `iridiumCoin`으로 서버의 실제 아이템 ID를 지정할 수 있다.
- 개인 보관함은 현재 최대 512개체이다. 가득 차면 인형을 소비하지 않는다. 인벤토리가 가득 차면 아이템화와 뽑기도 취소한다.
- 소환 엔티티는 청크에 영구 저장하지 않는다. 저장된 소환 의사와 보유 개체를 서버에서 확인하여 한 마리를 복구한다. 수동 소환 해제는 재접속 후에도 유지한다.

## 생활 뽑기권 발생률

기존 서버 생활 이벤트의 농사(성숙 작물 수확), 낚시(물고기), 채광(자연 광석), 요리(식용 제작/제련), 목축(번식)만 사용한다. 취소된 이벤트, 크리에이티브/관전자, 플레이어가 놓은 광석은 기존 게이트에서 제외한다. 자동 기계 생산과 지원하지 않는 모드의 별도 수확 이벤트를 임의로 성공 처리하지 않는다.

직전 정상 생활 행동과의 간격을 측정한다. 농사·요리 최대 10초, 낚시·채광 최대 30초, 목축 최대 60초까지만 활성 시간으로 센다. 한 틱의 대량 처리와 재접속/대기 시간으로 확률을 적립하지 않는다. 확률은 `1-exp(-활성틱/72000)`이며 기본 설정은 20 TPS에서 활성 시간 한 시간당 평균 약 한 장이다. 정시 확정 지급이 아니다. 위 간격보다 행동이 드문 플레이는 평균 지급량이 줄어든다. 전체 모드팩에서 행동 빈도를 측정한 보정값은 아니며 `ticketsPerActiveHour`에서 조정할 수 있다.

## 모델과 시안

`tools/generate_pet_models.py`가 만드는 원본 복셀 메시가 실제 게임 모델이다. 외형 시트 이미지를 평면으로 띄우지 않는다. 인형·소환체·보관함·상점 미리보기가 같은 메시를 사용한다. 눈/웃는 눈, 다리, 날개, 꼬리, 장식은 분리된 레이어다. `tools/art-sources/pet_catalog.json`이 60종의 고정 목록이다.

현재 외형은 기능 검증용 1차 3D 제작본이며, 승인한 풍부한 외형 시트의 세부 장식·질감까지 완성되었다고 간주하지 않는다. `validation/pets-0.9.0/screenshots`의 캡처는 이 실제 모델을 Minecraft가 렌더링한 것이며, 디자인 생성 이미지와 구분한다.
