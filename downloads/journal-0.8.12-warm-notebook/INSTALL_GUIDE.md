# 따뜻한 판타지 수첩 0.8.12

Minecraft 1.20.1 / Forge / Java 17용 Sunlit Journal입니다. 서버와 클라이언트의 기존 sunlit-journal-core JAR 하나를 sunlit-journal-core-0.8.12-warm-notebook.jar로 교체하세요. 중복 설치하지 않습니다.

꿈방울 모드 sunlit-reforged-1.0.0-dev.4.jar와 기존 연동 모드들은 그대로 사용합니다. 별도 리소스팩이나 데이터 변환은 필요 없습니다. 기존 월드·닉네임·칭호·업무·축제·보상 데이터 형식을 유지합니다.

달라지는 부분: 펼친 책 배경, 꿀빛 나무와 가죽 테두리, 꽃·덩굴 장식, 초록 선택 책갈피, 종이 카드와 닉네임 입력칸, 고정된 아래쪽 이동/닫기 버튼. 탭은 프로필 / 생활 기술 / 업무 일지 / 업적 도감 / 칭호 도감의 5개를 유지합니다.

소스 빌드: Java 17에서 저장소 루트 ./gradlew build. 최초 빌드는 Maven 접속이 필요합니다. 테스트·검증 스크립트의 외부 모드 JAR와 Gradle 캐시는 소스에 포함하지 않습니다.
