# 검증 범위

서버 GameTest 51개 통과(Forge 47.3.0). 실제 Minecraft 클라이언트에서 닉네임/Pufferfish Skills/Patchouli 및 꿈방울 애드온을 함께 불러 UI를 검사했습니다. 전체 모드팩 실행 또는 Essential 두 사용자 접속 검증은 아닙니다.

검사 항목: 5개 탭, 서버에서 받은 실제 프로필, 일일/주간/계절 하위 탭, 칭호 필터 및 서버 장착 요청, 스크롤/작은 GUI 버튼 경계, 닉네임 클릭 위치와 갱신 시 편집값·포커스 유지.

실제 게임 캡처는 validation/notebook-0.8.12/screenshots에 있습니다. real-* / small-*는 별도 테스트 월드의 실제 서버 데이터를 사용합니다. example-*는 기존 삽화·보상 레이아웃을 보기 위한 예시 데이터이며 화면에도 이를 표시합니다. 실제 모드팩의 레벨이나 플레이 기록으로 표시하지 않습니다.

UNCHANGED_SERVER.txt에 기존 서버·보상·칭호 로직의 동일성 확인 결과를 기록합니다.
