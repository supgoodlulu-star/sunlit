# 낚싯대 잠재능력 분리 — dev.7

Minecraft 1.20.1 / Forge 47.4.0 / Java 17.
서버와 모든 클라이언트의 기존 Sunlit Reforged JAR를 sunlit-reforged-1.0.0-dev.7.jar 하나로 교체합니다. 중복 설치하지 마세요. 수첩 sunlit-journal-core-0.8.13-nickname-text.jar와 글꼴 보정 모드는 그대로 사용합니다.

| 옵션 | 레어 | 에픽 | 유니크 | 레전드리 |
| --- | --- | --- | --- | --- |
| 희귀 물고기 확률 | 5% | 10% | 20% | 40% |
| 보물상자 등장 확률 | 10% | 20% | 30% | 50% |
| 낚시 막대 크기 증가 | 30% | 50% | 75% | 100% |

세 옵션은 각각 독립된 낚싯대 잠재옵션입니다. 낚싯대에는 이 세 옵션과 생활 경험치, 내구도 소모 방지 중에서 나옵니다. 전체 활성 옵션은 21개이며 중복 줄 규칙은 유지합니다.

막대 옵션은 Stardew Fishing 3.7의 현재 막대 길이를 기준으로 비례 증가시키고 정수 반올림합니다. 기본 36픽셀에서는 47 / 54 / 63 / 72픽셀이 됩니다. 다른 효과가 적용된 길이에도 비례하며, 원래 모드의 최소 16 / 최대 142픽셀 제한은 유지합니다. 보물 확률 보너스는 기존 확률에 퍼센트포인트로 더하고 최종 확률은 100%를 넘지 않습니다. 희귀 물고기는 기존 등장 가중치 3 이하와 계절·지역·날씨 조건을 유지합니다.

기존 장비의 희귀 어획 줄은 ‘이전 어획 보너스’로 표시하며 희귀 물고기와 보물에 주던 기존 효과 및 수치를 모두 유지합니다. 이 호환 옵션은 새로 뽑히지 않습니다. 기존 선택 대기 결과와 기존 옵션 선택도 보존합니다. 단순 조회는 기존 NBT를 다시 쓰지 않습니다. 새 저장 형식 및 네트워크가 바뀌므로 서버와 모든 클라이언트를 함께 업데이트하세요. 새 형식 장비는 이전 addon에서 읽을 수 없습니다.

기존 19옵션 데이터팩은 수정한 수치와 가중치를 유지하고 신규 두 옵션만 기본값으로 보충합니다. 제공한 sunlit_balance.zip을 월드 datapacks에 넣고 /reload 하거나 기존 동일 팩을 교체하면 전체 21옵션을 직접 조정할 수 있습니다. ZIP과 기존 팩을 중복 적용하지 마세요. default.json의 경로는 data/sunlit_reforged/potential_rules/default.json입니다.

꿈방울 가격 500 / 2,500 / 10,000 SUN, 승급 확률, 기존 19옵션 수치, 코인·업무 보상은 유지합니다. 황동 1개=64 SUN, 이리듐 1개=4,096 SUN입니다. 내부 꿈방울 레지스트리 ID도 유지합니다.

소스 빌드: addons/reforged/gradlew -p addons/reforged build. 외부 연동 모드는 소스에 포함하지 않습니다. 원본 Reforged JAR 미제공으로 해당 접두사 연동 완료판은 아닙니다.
