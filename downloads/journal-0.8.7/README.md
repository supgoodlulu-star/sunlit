# Sunlit Journal 0.8.7 — 아이템 자랑

수첩 0.8.6을 바탕으로 만든 Forge 1.20.1 / Java 17 버전입니다. 펫 기능은 포함하지 않습니다.

- `/자랑하기`: 손에 든 아이템을 전체 채팅에 두 줄로 자랑합니다.
- `쨔안~ [아이템]`: 일반 채팅의 `[아이템]`을 해당 아이템 표시로 바꿉니다.
- 아이템 이름에 마우스를 올리면 실제 툴팁이 나옵니다. 인챈트·설명·손상·커스텀 이름을 보존하며, 이후 아이템을 바꿔도 이전 채팅의 아이템 정보는 유지됩니다.
- 닉네임·대표 칭호·칭호 이미지와 함께 사용할 수 있습니다. 아이템은 소비하거나 복제하지 않습니다.

검증: 서버 테스트 37개, 실제 클라이언트의 명령·채팅·NBT 툴팁·닉네임·칭호·취소 처리, 정상 빌드 통과. 전체 운영 모드팩 검증은 별도입니다.
