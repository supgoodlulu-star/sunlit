# 구현 보고서 — 개발판

## 반영
- 독립 애드온 및 독립 NBT sunlit_reforged. 기존 Journal 기능·보상 유지.
- 큐브 3종, 19개 옵션, 장비별 풀, 등급 상승·하위 줄 확률, 최초 3레어, 마스터 이전/신규 선택. 승급은 이전 줄 선택에도 유지.
- 서버 메뉴·리비전 검사·선택 대기 장비 보관 및 직렬화 복원. 구매 시 실제 은행 차감, 인벤토리 공간 검사.
- 주 손 및 방어구 속성, 피해·흡혈·반사·채광·수확·내구도·생활 경험치 보너스.
- 생활 경험치는 실제 팩의 farming/fishing/husbandry/mining 분류. 요리는 팩의 farming 경험치에 포함됩니다.
- Journal 완료 이벤트 추가 및 기존 보상 뒤 추가 큐브 추첨. 일일 5%, 주간 10%, 축제 2%. 기존 화폐·경험치 지급은 변경하지 않습니다.
- 희귀 어획: 사용자 승인 기준 등장 가중치 3 이하. 공개 4.1.5A의 105개 계절·수역·날씨·시간 항목을 사용합니다. 해당 조건을 만족하는 일반 어획에 추가 추첨 후 물고기 1개만 바꿉니다. 총 수량·다른 보상·잠긴 특수 물고기는 유지합니다. 전체 어획의 최종 희귀 확률이 옵션 수치만큼 단순 증가한다는 뜻은 아닙니다.
- 보물: Stardew Fishing의 실제 미니게임 보물 확률 API에 옵션 합을 가산합니다. 확률만 0~100%로 제한합니다. 성공한 보물 낚시의 큐브 추첨은 낚싯바늘별 한 번입니다.
- 기존 팩에서 꺼 둔 전설 물고기 시스템은 다시 켜지 않습니다.
- 툴팁과 Journal 아이템 자랑의 실제 아이템 정보에 잠재능력 표시.

## 확인 자료
Society: Sunlit Valley 4.1.5A, Modrinth version YbSKGvHk (Forge 47.4.0). 실제 관련 모드 JAR 및 팩 스크립트/설정을 분석했습니다. 전체 모드팩을 완전히 재현한 테스트가 아닌 관련 모드 조합 테스트입니다.

## 미완료·한계
- 사용 중인 Reforged 원본 JAR가 없습니다. 실제 접두사 API/NBT, 초기화 시 잠재능력 유지, 접두사 툴팁은 검증·구현 완료로 표시하지 않습니다. 외부 NBT 보존과 바닐라 대장장이 변환 테스트가 실제 Reforged 초기화 호환을 증명하지 않습니다.
- 플레이어 설치 광석과 FakePlayer 자동화는 제외합니다. 피스톤·모드 전용 이동/설치 시스템을 거친 광석의 출처 추적은 아직 검증하지 않았습니다.
- 실제 두 클라이언트 Essential 접속, 전체 4.1.5A 모드팩 및 사용자 서버 검증은 남아 있습니다.
- 선택 대기는 서버 SavedData에 저장됩니다. Minecraft 저장 파일 전체에 대한 강제 종료 시 원자적 거래를 보장하지 않습니다.
- 동전·아이템 최대 개수와 외부 은행 int 거래 한도는 적용됩니다. 잠재능력 총합에 임의 상한을 두지 않습니다.

screenshots는 실제 Minecraft 클라이언트 캡처입니다. 디자인 시안이나 완성된 Reforged 접두사 통합 화면으로 표시하지 않습니다.

## 공방 UI 변경
사용자 제공 시안을 참고해 생성한 나무 공방 배경 텍스처를 적용했습니다. 문자·가격·아이템·옵션·버튼·슬롯은 게임에서 표시합니다. 장비/큐브, 잠재능력, 구매 목록을 세 영역으로 나누고 인벤토리는 아래에 배치했습니다. 화면에 맞춰 UI와 마우스 좌표를 같은 비율로 축소합니다. 배경 자체에는 고정된 수치·아이템 정보가 없습니다.

## 1.0.0-dev.3 변경
사용자 요청으로 재련 망치를 제거했습니다. 상점 상품·구매 처리·설정에서 제외하고 큐브 3종만 판매합니다. 빈 자리는 사용 가능한 장비 안내로 바꿨습니다. 이전 데이터팩의 가격 4개 형식은 앞의 큐브 가격 3개만 읽으며, 이전 망치 설정은 무시합니다. 삭제한 상품 번호의 구매 요청은 차감 없이 거절합니다. 기존 장비 NBT와 큐브 기능은 유지합니다.
