- 큐브 최초 부여/승급/3줄 분포/중복/장비 풀/잘못된 장비 거절

- 실제 Numismatics 계좌 차감, 잔액 부족·인벤토리 부족·중복 구매 방지
- 실제 Pufferfish 경험치 지급 시점 보정과 소수 누적
- 장비 장착/해제, 공격·처형·흡혈·피해 감소·반사·이동·점프·내구도
- 자연 광석/설치 광석/FakePlayer 및 성숙 작물/미성숙 작물 구분
- 실제 낚시 이벤트 보물 확률, 보물 큐브 중복 방지

- 실제 GUI 슬롯/패킷/이전 줄 선택/창 재열기/구매/아이템 자랑 호버/작은 GUI 배율

아직 필요한 확인: Reforged 원본 접두사·초기화 호환, 전체 모드팩, Essential 두 사용자 접속, 실제 서버 재시작 복원, 피스톤 및 다른 모드의 블록 이동.

## 1.0.0-dev.3 변경
사용자 요청으로 재련 망치를 제거했습니다. 상점 상품·구매 처리·설정에서 제외하고 큐브 3종만 판매합니다. 빈 자리는 사용 가능한 장비 안내로 바꿨습니다. 이전 데이터팩의 가격 4개 형식은 앞의 큐브 가격 3개만 읽으며, 이전 망치 설정은 무시합니다. 삭제한 상품 번호의 구매 요청은 차감 없이 거절합니다. 기존 장비 NBT와 큐브 기능은 유지합니다.
