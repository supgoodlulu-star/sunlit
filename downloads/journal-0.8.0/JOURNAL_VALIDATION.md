## 이미지 구분

이번에 생성형 디자인 시안은 만들지 않았습니다. 대화에 승인 이미지 파일이 전달되지 않아 텍스트의 색·재질·아이콘·탭 요구사항을 코드로 구현했습니다. 첨부 시안과 픽셀 단위로 일치한다고 주장하지 않습니다.

- `profile-live.png`, `titles-equipped.png`, `titles-unowned.png`, `rewards-*.png`: 실제 Minecraft 클라이언트 + 전용 통합 서버 테스트 월드의 화면입니다. 테스트가 업무·칭호 상태를 준비하고, 실제 수령/장착 패킷과 서버 데이터를 사용했습니다. 일반 플레이로 해당 상태를 모두 달성했다는 뜻은 아닙니다.
- `cards-*.png`: 실제 Minecraft 렌더러에 **예시 스냅샷 데이터**를 넣은 UI 검증 화면입니다. 화면 하단에 이 구분을 표시했습니다. 기술 레벨 7·업무 목표 6 등은 해당 촬영의 테스트 데이터이며 실제 조건을 바꾼 것이 아닙니다.
- 보상 연동 아이템은 테스트 전용 등록/바닐라 대체 아이콘을 사용한 부분이 있습니다. 스크린샷 하단에도 표시했습니다. 실제 전체 모드팩의 아이콘/아이템 검증으로 볼 수 없습니다. 테스트용 아이템·도구는 배포 JAR에 들어가지 않습니다.

## 남은 실제 모드팩 검증

사용자의 전체 모드팩·Pufferfish 카테고리 설정·실제 플레이어 월드는 제공되지 않았습니다. 기존 보상 ID를 그대로 유지했으며 아이템 ID와 수량을 임의로 바꾸지 않았습니다. 실제 비료/사료/지렁이/통발 미끼/알프스 소금/화폐의 등록, 전체 카테고리 레벨 곡선, 대규모 서버·인터넷 멀티플레이·Essential·셰이더 환경까지 검증한 결과는 아닙니다. 연동 API 검사 통과는 모드팩 전체의 카테고리 데이터 확인과 구분됩니다.

기존 저장 키와 미사용 소유 NBT, 비활성 아이템 ID를 보존하도록 구현하고 합성 구버전 저장 상태를 재로드했습니다. 사용자의 실제 0.7.0 월드 사본 업그레이드는 아직 검사하지 않았습니다. 서버·클라이언트 JAR를 함께 바꾸고 실제 월드는 백업 사본으로 먼저 확인하세요. 보상이 준비되지 않으면 진행도/수령권을 보존하고 보상 전체를 보류합니다.
