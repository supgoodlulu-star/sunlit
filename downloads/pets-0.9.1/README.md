- 서버 GameTest 40개, 메시 생성기 테스트 4개, 60종 자산 검사와 실제 클라이언트 기능 흐름 검증 통과

기존 0.9.0 개체·장식 기록과 저장 형식, 보상·추첨 규칙은 유지합니다. 같은 모드 ID의 기존 Sunlit JAR를 교체하여 클라이언트와 서버에 설치합니다.

소스 커밋: `ae05e22a9d4ce50839d4ac8c6d7fec9458cfe5c2`

현재 메시의 원본은 코드와 커스텀 JSON입니다. Blockbench 전문 작업자가 수작업한 `.bbmodel` 프로젝트라고 표시하지 않습니다. 승인 시트 PNG는 비교 자료이며 배포 JAR에 넣지 않았습니다.
