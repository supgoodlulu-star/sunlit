# 선릿 명예의 전당 0.8.9

기존 Sunlit JAR를 제거하고 새 JAR를 서버와 클라이언트에 동일하게 설치하세요. Minecraft 1.20.1 / Forge 47.3.0 / Java 17.

운영자가 원하는 자리에 서서 `/명예의전당 채광` 또는 `/명예의 전당 채광`을 입력하면 해당 분야 1위 인형 하나만 정확한 현재 위치·방향으로 설치됩니다. 농사·낚시·요리·목축·업무·축제·업적도 지원합니다. 블록 생성/변경은 없으며 직접 건축할 수 있습니다.

`/명예의전당 제거`: 5칸 안에서 가장 가까운 인형 하나만 제거합니다. `/명예의전당`: 전체 순위 조회. 인형 우클릭도 지원합니다.

기존 1위는 유지하고 2·3위 인형은 해당 청크 로드 후 정리합니다. 기존 단상 블록과 모든 기록은 유지합니다. 월간 갱신과 보상 없음도 동일합니다.
