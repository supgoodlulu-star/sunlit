# 레디오 볼펜체 볼드 겹침 수정

**Sunlit_Radio_Ballpen_BoldFix_Bundle.zip**을 받으면 보정 모드와 수정 리소스팩이 함께 들어 있습니다.

1. 묶음 ZIP을 풉니다.
2. mods 안의 JAR를 클라이언트 mods 폴더에 추가합니다.
3. resourcepacks 안의 ZIP을 클라이언트 resourcepacks 폴더에 넣습니다. 리소스팩 ZIP 자체는 풀지 않습니다.
4. 게임을 재시작하고 기존 Radio Ballpen 팩 대신 수정 팩을 켭니다.

Minecraft 1.20.1 / Forge 47.3.0 / Java 17 클라이언트 전용. 서버 설치는 필요하지 않습니다. 두 파일을 함께 사용해야 볼드 보정이 적용됩니다.

원본 PNG와 일반 자간/크기는 유지하고, 볼드 덧그림 간격만 1픽셀에서 0.25픽셀로 줄였습니다. 기본/대체 글꼴은 그대로입니다. 실제 클라이언트에서 완성 JAR+ZIP 설치, 리소스 새로고침, 일반 글씨 픽셀 동일성 및 별도 소스 빌드를 검증했습니다.
