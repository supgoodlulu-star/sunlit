선릿 레디오 볼펜체 볼드 겹침 수정

Minecraft 1.20.1 / Forge 47.3.0 / Java 17

1. mods 폴더의 JAR를 마인크래프트 클라이언트 mods 폴더에 추가하세요.
2. resourcepacks 폴더의 ZIP을 클라이언트 resourcepacks 폴더에 넣으세요.
3. 게임을 재시작하고 리소스팩 설정에서 기존 Radio Ballpen 팩을 끈 뒤 수정 팩을 켜세요.

클라이언트 전용 보정 모드로 서버 설치는 필요하지 않습니다. 기존 Sunlit 모드에 추가해서 사용합니다.
리소스팩 ZIP은 압축을 풀지 마세요. 이 배포 묶음 ZIP만 풀어서 각 폴더에 넣으면 됩니다.

원본 글꼴 PNG와 일반 자간/크기는 유지했습니다. Minecraft의 볼드 덧그림 간격을 1픽셀에서 0.25픽셀로 줄입니다. 기본 마인크래프트 및 대체 글꼴에는 적용하지 않습니다.
보정은 JAR가 담당하므로 리소스팩 ZIP만으로는 볼드 간격이 바뀌지 않습니다.

설정 파일: config/sunlit_font_bold_fix-client.toml / boldOffset=0.25
0.0은 볼드 수평 이동을 없애고 1.0은 바닐라 간격입니다.

실제 클라이언트에서 JAR+ZIP 별도 설치 및 리소스 새로고침을 검증했습니다.
