# 0.8.1-journal · 승인 시안 삽화 및 계절 공동 축제

0.8.0에서 간단한 도트 기호로 축약했던 생활 분야 그림을 수정했습니다. 사용자 첨부 시안의 구도·소품·색감을 참고해 게임용 삽화 12종을 새로 제작했습니다. 첨부된 시안 원본을 그대로 잘라낸 이미지라고 주장하지 않습니다.

## 실제 코드·리소스 변경

- 농사: 밀·분홍 꽃·새싹·물방울 / 낚시: 푸른 물고기·물결·물방울·진주.
- 채광: 구리 곡괭이·보라/파랑 수정 / 요리: 구리 냄비·스튜·나무 숟가락·허브.
- 목축: 송아지·황금 종·클로버·꽃 / 탐험: 황동 나침반·지도·나뭇잎.
- 생활: 자수·바느질 바구니·실타래·라벤더 / 서적: 보라색 마법책·초승달·별.
- 각 삽화는 투명 배경의 256×256 PNG입니다. 생활 기술 카드에서는 GUI 공간에 따라 80/104픽셀 크기로 표시하고 이름·실제 레벨/경험치·해금 상태를 옆에 배치합니다. 일일/주간 업무·업적·칭호의 작은 분야 표식도 같은 그림을 사용합니다.
- API에서 읽은 실제 카테고리만 표시하며 그림이 8종이라는 이유로 존재하지 않는 카테고리·레벨을 추가하지 않습니다. 기존 확장/원본 스킬 트리 버튼을 유지합니다.

## 계절 공동 축제

사용자가 선택한 범위는 **기존 공동 축제부터 완성**입니다. 개인 계절 임무, 새로운 목표·보상, 뽑기 보너스는 추가하지 않습니다.

| 계절 | 기존 축제 | 새 그림 |
|---|---|---|
| 봄 | 벚꽃 축제 | 벚꽃 가지·씨앗 봉투·새싹·꽃 바구니 |
| 여름 | 별빛 해변 축제 | 물고기·낚싯대·조개·물결·별 등불 |
| 가을 | 풍요의 수확제 | 수확 바구니·밀·호박·사과·단풍 |
| 겨울 | 눈꽃 축제 | 눈꽃·전나무·따뜻한 스튜·촛불·목도리 |

‘업무 일지 → 계절 특별 업무’에서 현재 축제를 먼저 표시합니다. 실제 서버의 공동 목표/진행도와 개인 기여도, 기여 조건, 달성 상태, 기존 보상(에메랄드 16 + 경험치 160)을 보여줍니다. 다른 계절은 ‘계절 대기’이며 가짜 진행도나 수령 버튼을 만들지 않습니다. 계절 API를 읽을 수 없으면 대기 안내를 표시합니다. 획득한 계절 칭호와 참여 기록은 기존 저장 데이터를 사용합니다. 총 5개 수첩 탭을 유지합니다.

## 검증 및 이미지 구분

- 0.8.1의 클린 빌드 성공 및 서버 GameTest 28개 전부 통과.
- 실제 Minecraft 렌더러에서 생활 분야 8종, 계절 4종, 계절 연동 없음/축제 완료/작은 GUI 상태 4종을 별도로 촬영했습니다. 1280×900 GUI 2와 960×720 GUI 3을 포함합니다.
- `art-skill-*.png`, `art-festival-*.png`, `art-state-*.png`는 **게임 렌더러로 실행·촬영한 UI 검증 화면**입니다. 설명과 달성 상태를 확인하기 위해 예시 서버 스냅샷 데이터를 사용했으며 화면 하단에도 이를 표시합니다. 전체 모드팩에서 실제 축제를 완료한 플레이 기록과는 다릅니다.
- `tools/art-sources/life-and-seasons.png`는 제작한 삽화 원본 시트이며 게임 화면이 아닙니다. `tools/slice_journal_art.py`는 이 시트를 PNG 12종으로 기계적으로 분리·정사각 패딩·최근접 리사이즈합니다. 주변 그림 조각이 들어오지 않도록 행 사이 여백을 제외했습니다.
- JAR에는 삽화 PNG 12종이 모두 포함되고 테스트용 아이템/화면 및 스킨 실행 코드는 포함되지 않습니다.
- 전체 사용자 모드팩·실제 세이브·Serene Seasons의 실제 계절 전환까지 새로 검증한 것은 아닙니다. 실제 게임 수치는 기존 API·설정·저장 데이터를 따릅니다. 이 변경에서는 서버 임무/보상/저장 로직을 수정하지 않았습니다.

## 다시 촬영하기

JDK 17, X11/OpenGL, 캐시가 준비된 개발 환경에서:

```sh
./gradlew -I tools/visual-preview/art-preview.gradle runClient
```

이 도구는 배포 JAR에 포함되지 않습니다. 리소스 누락·겹침·카테고리별 외형을 확인하기 위한 예시 데이터 촬영이며 실제 모드팩 통합 검사는 별도로 필요합니다.
