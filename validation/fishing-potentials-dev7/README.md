# 실제 낚시 화면 검증

screenshots는 Minecraft 1.20.1 / Forge 47.4.0 및 실제 Stardew Fishing 3.7을 실행해 캡처한 화면입니다. 생성 이미지가 아닙니다.

기본 36픽셀과 레전드리 막대 잠재옵션 +100%의 72픽셀을 비교합니다. QA 전용 테스트 낚싯대에 실제 잠재옵션을 저장하고 운영 코드의 Forge 이벤트 처리 → 서버 패킷 → 네이티브 FishingScreen으로 확인했습니다. 비교를 위해 물고기·막대 위치와 진행도를 고정하고 HUD를 숨겼습니다. 이것은 비교용 테스트 월드이며 전체 모드팩 실전 플레이 캡처는 아닙니다.

서버 게임테스트 30개 통과: 신규 옵션 분리, 기존 복합 줄 보존, 선택 대기, 구형 데이터팩, 4개 등급 길이, 네이티브 최대 제한 등을 포함합니다.
