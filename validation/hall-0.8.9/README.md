# 0.8.9 1위 단독 전시 검증

실제 Minecraft Forge 1.20.1 / 47.3.0 클라이언트, 격리된 SunlitHallTest 월드. 순위/점수는 QA 예시입니다.

전시대는 QA가 직접 블록을 쌓은 예시 구조물입니다. **설치 명령은 블록을 만들지 않습니다.**

서버: 기존 기능과 추가 회귀 검사를 포함한 47 GameTests 통과. 한글 명령 및 띄어쓰기 별칭, OP 권한, 정확한 좌표/방향, 인형 1개 생성, 주변 블록 무변경, 기존 2·3위 인형 정리 확인.

실제 게임 캡처는 screenshots/에 저장합니다. QA는 배포 JAR에 포함되지 않으며 전체 사용자 모드팩 검증은 별도입니다.

실제 클라이언트 검증 통과: 한글 설치 명령, 1개 인형만 존재, 서버 순위 변화에 따른 인물 교체, 우클릭, 작은 GUI, 프로필 진입 및 닫기 (`HALL_CLIENT_PASSED`).
