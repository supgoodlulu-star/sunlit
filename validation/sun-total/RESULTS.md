# 글자 겹침과 SUN 기준 검증

수첩 서버 GameTest 51/51, 꿈방울 서버 GameTest 24/24 통과.
실제 라디오 볼펜 글꼴과 기존 보정 모드를 불러 닉네임 입력의 그림자 없는 렌더링, 커서 앞뒤 연결, 포커스·선택·긴 입력·작은 GUI·백스페이스·갱신 보존을 확인했습니다. 캡처는 ../nickname-text-0.8.13/screenshots입니다.

실제 Numismatics 계좌의 4,096 SUN에서 500 SUN 구매 → 3,596 SUN, 이어서 2,500 SUN 구매 → 1,096 SUN을 확인했습니다. 수첩과 꿈방울 양쪽의 단위가 1 최소 단위인지 검사했습니다. 구형 assetUnit=4096 저장 기록도 원래의 최소 단위 금액으로 표시합니다.

실제 상점 UI 구매·선택·복원·작은 GUI를 확인했으며 캡처는 ../sun-total-reforged/screenshots입니다. 전체 사용자 모드팩 또는 Essential 2인 접속을 새로 검증한 것은 아닙니다.
