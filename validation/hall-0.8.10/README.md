# 0.8.10 검증

49개 서버 GameTests 통과: 자산 입출금에 따른 순위 역전, 잔액 월말 보관, 새 달의 현재 자산 유지, 재시작, 연동 실패 시 마지막 확인값 보존, 정확한 소수 통화 표시, 기존 명령·집계 기능 회귀 검증.

실제 클라이언트에서 자산 인형 한 명 배치, 순위·전시 인물 교체, 인형 우클릭, 작은 GUI, 수첩 버튼 제거, 명령어 조회 유지 확인 (`HALL_CLIENT_PASSED`).

캡처는 실제 게임 화면이며 잔액/순위는 격리된 QA 월드의 **예시 데이터**입니다. 테스트 단상은 QA가 만든 구조물로 설치 명령은 블록을 만들지 않습니다. 배포 JAR에는 QA를 포함하지 않습니다.

개발 환경에는 실제 Numismatics 전체 모드팩이 없어 실제 계좌 조회의 최종 연동 검증은 별도입니다. 캡처는 실제 은행 계좌 데이터가 아닙니다.

소스 ZIP 독립 빌드 성공. 배포 JAR의 모든 엔트리 내용 일치 및 SHA-256 검증 완료.
